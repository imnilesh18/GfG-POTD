## 📝 Problem Statement

Given a positive integer `n`, consider a `4n * 4n` matrix filled with integers from `1` to `(4n) * (4n)` in row-major order (left to right, top to bottom)[cite: 1]. 

Your task is to form two coils from the matrix[cite: 1]:
* The first coil starts from the top-left cell `(0, 0)` and spirals inward[cite: 1].
* The second coil starts from the bottom-right cell `(4n - 1, 4n - 1)` and spirals inward in the opposite direction[cite: 1].

Return these two coils in the same order[cite: 1].

---

## 🛑 Constraints

> - `1 ≤ n ≤ 20`[cite: 1]
> - **Expected Time Complexity:** `O(n^2)`[cite: 1]
> - **Expected Auxiliary Space:** `O(n^2)`[cite: 1]

## 🚀 Solution Approaches

### Mathematical Reflection (Optimized Approach)

Instead of simulating both spirals, we can simulate only the first coil and utilize the symmetric property of the matrix to generate the second coil. If the total number of elements in the matrix is $16n^2$, any value $x$ in the first coil perfectly mirrors a value $(16n^2 + 1) - x$ in the second coil.

```cpp
// Intuition: The matrix is perfectly symmetric. Instead of traversing the matrix twice, we can simulate the inward spiral for the first coil and mathematically derive the second coil's elements using the formula `(max_val + 1) - x`.
// Approach: 
// 1. Calculate the matrix dimensions `N = 4n` and maximum value `max_val = 16n^2`.
// 2. Simulate the first coil starting from the top-left (0,0) by moving Down, Right, Up, and Left.
// 3. The step sizes follow a strict decreasing sequence, shrinking by 2 after every pair of direction changes.
// 4. Derive the second coil by subtracting each value of the first coil from `(max_val + 1)`.
// Time Complexity: O(n^2) since we iterate exactly 8*n^2 times to build each coil list.
// Space Complexity: O(n^2) auxiliary space to store the results before returning them.

class Solution {
  public:
    vector<vector<int>> formCoils(int n) {
        int N = 4 * n;
        int max_val = N * N; // Calculate max element, which is 16n^2

        vector<int> coil1;
        coil1.reserve(8 * n * n); // Preallocate space: Each coil contains half of the elements

        // Start at top-left
        int r = 0, c = 0;
        coil1.push_back(r * N + c + 1);

        // Directions mapping: Down (0), Right (1), Up (2), Left (3)
        int dr[] = {1, 0, -1, 0};
        int dc[] = {0, 1, 0, -1};
        int dir = 0; // Initial direction is Down

        // The very first step length moving downwards
        int step = 4 * n - 1;

        // Make the initial downward movement
        for (int i = 0; i < step; ++i) {
            r += dr[dir];
            c += dc[dir];
            coil1.push_back(r * N + c + 1);
        }

        dir = (dir + 1) % 4; // Change direction 90 degrees
        step = 4 * n - 2;    // Decrease step size for the upcoming pair loops

        // Loop for the remaining spiral movements
        while (step >= 2) {
            // We make two movements of the same step size before decreasing
            for (int j = 0; j < 2; ++j) {
                for (int i = 0; i < step; ++i) {
                    r += dr[dir];
                    c += dc[dir];
                    coil1.push_back(r * N + c + 1);
                }
                dir = (dir + 1) % 4; // Turn 90 degrees
            }
            step -= 2; // Decrease step size by 2 as the spiral tightens
        }

        // Generate Coil 2 mathematically by reflecting Coil 1
        vector<int> coil2;
        coil2.reserve(8 * n * n);
        for (int x : coil1) {
            // Element in coil2 is the complement of element in coil1
            coil2.push_back((max_val + 1) - x); 
        }

        return {coil1, coil2};
    }
};

/*
*
* Dry Run
* Input: n = 1
* Variables: N = 4, max_val = 16
* coil1 initialization: starts at top-left (r=0, c=0), value = 1.
* Initial downward movement: step = 3. Moves to 5, 9, 13.
* Next loop iteration: step = 2.
* -> Moves Right twice: 14, 15.
* -> Moves Up twice: 11, 7.
* step becomes 0, breaking the loop. 
* coil1 = [1, 5, 9, 13, 14, 15, 11, 7]
* coil2 calculation: (16 + 1) - x for each x in coil1.
* coil2 = [17-1, 17-5, 17-9, 17-13, 17-14, 17-15, 17-11, 17-7]
* coil2 = [16, 12, 8, 4, 3, 2, 6, 10]
* Output: [[1, 5, 9, 13, 14, 15, 11, 7], [16, 12, 8, 4, 3, 2, 6, 10]]
*
*/

```

## 🧠 Key Insights

* **Symmetry is Powerful:** Realizing that the matrix possesses inverse symmetry allows us to bypass the complex logic of tracking boundaries and pointer variables for the second spiral traversing backwards.
* **Matrix coordinate flat-mapping:** The formula `r * N + c + 1` maps a 2D matrix coordinate `(r, c)` instantly into its 1D numerical value without explicitly generating a massive 2D array in memory. This saves $O(n^2)$ extra spatial initialization cost.
