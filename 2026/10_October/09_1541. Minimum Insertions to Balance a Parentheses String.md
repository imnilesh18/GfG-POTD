# 1541. Minimum Insertions to Balance a Parentheses String

**Difficulty:** Medium 🟡  
**Tags:** `String`, `Stack`, `Greedy`, `Bracket Sequences`  

---

## 🔗 Problem Link
[1541. Minimum Insertions to Balance a Parentheses String](https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string)

## 📝 Problem Statement
Given a parentheses string `s` containing only the characters `'('` and `')'`. A parentheses string is balanced if:

1. Any left parenthesis `'('` must have a corresponding two consecutive right parenthesis `'))'`.
2. Left parenthesis `'('` must go before the corresponding two consecutive right parenthesis `'))'`.

In other words, we treat `'('` as an opening parenthesis and `'))'` as a closing parenthesis.

For example, `"())"`, `"())(())))"` and `"(())())))"` are balanced, `")()"`, `"())))"` and `"(()))"` are not balanced.
You can insert the characters `'('` and `')'` at any position of the string to balance it if needed.

Return the minimum number of insertions needed to make `s` balanced.

### Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `s = "(()))"` | `1` | The second `'('` has two matching `'))'`, but the first `'('` has only `')'` matching. We need to add one more `')'` at the end of the string to be `"(())))"` which is balanced. |
| **2** | `s = "())"` | `0` | The string is already balanced. |
| **3** | `s = "))())("` | `3` | Add `'('` to match the first `'))'`, Add `'))'` to match the last `'('`. |

### Constraints
- `1 <= s.length <= 10^5`
- `s` consists of `'('` and `')'` only.

---

## 💡 Key Insights & Explanation

To solve this problem, we need to ensure that every opening bracket `'('` is followed by exactly two closing brackets `'))'`. A greedy approach works perfectly here.

We can maintain a `count` variable to track our available, unmatched opening brackets. 
As we iterate through the string:
1. **If we see an `'('`**: We simply increment our `count`.
2. **If we see a `')'`**: We need to resolve a pair of closing brackets for an opening one.
   - First, we check if we have an unmatched opening bracket available (`count > 0`). If we do, we consume one (`count--`). If we don't, it means we are missing an opening bracket, so we must insert one (`result++`).
   - Next, we look at the immediate next character. If it is also a `')'`, then we have found our required `'))'` pair, and we can simply skip that next character by incrementing our loop index extra. If the next character is *not* a `')'` (or we are at the end of the string), we are missing the second half of the closing pair. Thus, we must insert a `')'` (`result++`).

After we finish traversing the string, we might still have some unmatched opening brackets left in our `count`. Since every single opening bracket requires exactly *two* closing brackets, we need to add `2 * count` insertions to our final result.

---

## 🚀 Approach

1. Initialize `result = 0` to track total insertions and `count = 0` to track active opening brackets.
2. Iterate through the string `s` using a `while` loop.
3. Upon encountering `'('`, increment `count` and move to the next character.
4. Upon encountering `')'`, check `count`:
   - If `count > 0`, decrement it (matching with a previous `'('`).
   - If `count == 0`, increment `result` (inserting a missing `'('`).
5. Then, look ahead to `s[i + 1]`:
   - If it is also `')'`, we have a valid `'))'` pair. Advance the index by 2 (`i += 2`).
   - If it is not `')'`, increment `result` (inserting a missing `')'`) and advance the index by 1 (`i++`).
6. Finally, return `result + (2 * count)` to account for any unmatched opening brackets remaining at the end.

## 💻 Solution Code

### Optimized Solution (C++)

```cpp
// Intuition: Every '(' requires exactly two consecutive ')'. We can track unmatched '(' and greedily insert missing brackets as we traverse the string.
// Approach: Iterate through the string, updating the count of unmatched '('. When encountering ')', check for a preceding '(' and look ahead for a consecutive ')', adding insertions whenever a required bracket is missing.
// Time Complexity: O(n) where n is the length of the string, as we traverse it exactly once.
// Space Complexity: O(1) because we are only using a few integer variables for counting and indexing.

class Solution {
public:
    int minInsertions(string s) {
        int n = s.length();
        int result = 0;  // Tracks total insertions needed
        int count = 0;   // Tracks unmatched '('
        int i = 0;

        while(i < n) {
            if(s[i] == '(') {
                count++;
                i++;
            } else {  // Encounters ')'
                // Check if we have a matching '('
                if(count > 0) {
                    count--;
                } else {
                    result++; // Need to insert a '('
                }

                // Check if the next character is also ')'
                if(i + 1 < n && s[i + 1] == ')') {
                    i += 2;   // Skip the next ')' as it forms a valid pair
                } else {
                    result++; // Need to insert a second ')'
                    i++;
                }
            }
        }
        
        // Add 2 closing brackets for every unmatched opening bracket left
        return result + 2 * count;
    }
};

/*
*
* Dry Run
* Input: s = "(()))"
* 
* Initialization: n = 5, result = 0, count = 0, i = 0
* 
* Step 1 (i = 0, s[0] = '('):
*   count becomes 1. i becomes 1.
* 
* Step 2 (i = 1, s[1] = '('):
*   count becomes 2. i becomes 2.
* 
* Step 3 (i = 2, s[2] = ')'):
*   count > 0, so count becomes 1.
*   s[i+1] is s[3] which is ')'. Condition met. i += 2 -> i becomes 4.
* 
* Step 4 (i = 4, s[4] = ')'):
*   count > 0, so count becomes 0.
*   s[i+1] is out of bounds (i+1 = 5, n = 5). Condition fails.
*   result++, i++. result becomes 1, i becomes 5.
* 
* Loop Ends (i = 5).
* Final Calculation: result + 2 * count = 1 + 2 * 0 = 1.
* Output: 1
*
*/

```
