# 3505. Minimum Operations to Make Elements Within K Subarrays Equal

**Problem Link:** [Minimum Operations to Make Elements Within K Subarrays Equal](https://leetcode.com/problems/minimum-operations-to-make-elements-within-k-subarrays-equal/)  
**Difficulty:** Hard  
**Tags:** `Array`, `Hash Table`, `Math`, `Dynamic Programming`, `Sliding Window`, `Heap (Priority Queue)`  

---

## 📝 Problem Statement

You are given an integer array `nums` and two integers, `x` and `k`. You can perform the following operation any number of times (including zero):

- Increase or decrease any element of `nums` by 1.

Return the minimum number of operations needed to have at least `k` non-overlapping subarrays of size exactly `x` in `nums`, where all elements within each subarray are equal.

### Constraints:
- `2 <= nums.length <= 10^5`
- `-10^6 <= nums[i] <= 10^6`
- `2 <= x <= nums.length`
- `1 <= k <= 15`
- `2 <= k * x <= nums.length`

## 🧠 Key Insights & Approach

### 1. Efficient Median Finding in Subarrays
To make elements of a subarray equal using minimum operations, we must convert all elements to their **median**. 
Finding the median for every subarray of size $X$ using brute force (sorting) takes $O(X \log X)$ per window, which is too slow. Using `nth_element` alters the array structure, disrupting the sliding window.

### 2. The Two-Multiset Sliding Window
To efficiently track the median of a sliding window of size $X$, we maintain two `multiset` data structures:
- **Left Multiset (`f`):** Stores the smaller half of the elements in a sorted manner.
- **Right Multiset (`s`):** Stores the larger half of the elements in a sorted manner.

**Balancing Rules:**
- The size of the Left multiset should be equal to the Right multiset, or exactly one element larger if $X$ is odd.
- The maximum element in the Left multiset must always be less than or equal to the minimum element in the Right multiset. 
- If this condition is violated during window sliding, we swap the maximum of the Left with the minimum of the Right (Adjustment/Rebalancing).

By maintaining these properties, the **median** will always be the largest element in the Left multiset (i.e., `*f.rbegin()`).

### 3. Dynamic Programming for Subarray Selection
Once we have precalculated the minimum operations required for every possible subarray of size $X$ (stored in `mvs` array), the problem reduces to selecting $K$ non-overlapping subarrays such that the sum of their operations is minimized.
We define a DP state `solve(par, i)`:
- `par`: Number of subarrays chosen so far.
- `i`: Current index in the array.
- We have two choices: skip the current index `i`, or pick a subarray starting at `i` (which costs `mvs[i]` and jumps to index `i + X`).

## 💻 Solution Code

```cpp
// Intuition: The minimum operations to make an array equal is achieved by making all elements equal to the median. We can find the median of every sliding window of size X using two multisets. Then, use DP to find K non-overlapping windows that yield the minimum total operations.
// Approach: 
// 1. Maintain two multisets to track the median of a sliding window of size X.
// 2. Keep track of the sum of elements in both multisets (s1 and s2) to calculate operations efficiently in O(1) time once the median is found.
// 3. Store the cost for each window in an array `mvs`.
// 4. Use a recursive DP with memoization to select K non-overlapping windows minimizing the sum of costs from `mvs`.
// Time Complexity: O(N * log X + N * K) where N is the length of nums. Sliding window takes O(N log X) and DP takes O(N * K).
// Space Complexity: O(N * K + X) for the DP table memoization and the two multisets storing X elements.

class Solution {
public:
    int n;
    long long dp[16][100001]; // DP table for K up to 15, N up to 10^5
    long long mvs[100001];    // Minimum operations for a window starting at index i
    int k;
    int x;

    // Recursive DP to find optimal non-overlapping subarrays
    long long solve(int par, int i) {
        // Base case: successfully found K subarrays
        if (par == k) {
            return 0;
        }
        // Base case: reached end of array without finding K subarrays
        if (i == n) {
            return 1e15; // Infinity equivalent
        }
        // Return memoized result
        if (dp[par][i] != -1) 
            return dp[par][i];
            
        long long ans = 9e18;

        // Option 1: Pick the subarray of size X starting at index i
        if (i + x - 1 < n) {
            ans = min(ans, mvs[i] + solve(par + 1, i + x));
        }
        // Option 2: Skip the current index
        ans = min(ans, solve(par, i + 1));
        
        return dp[par][i] = ans;
    }
    
    long long minOperations(vector<int>& a, int X, int K) {
        n = a.size();
        k = K;
        x = X;
        
        multiset<int> f; // Left multiset (smaller elements)
        multiset<int> s; // Right multiset (larger elements)
        long long s1 = 0; // Sum of elements in Left
        long long s2 = 0; // Sum of elements in Right
        
        for (int i = 0; i < n; i++) {
            // Remove the element that slides out of the window
            if (i >= x) {
                if (f.find(a[i - x]) != f.end()) {
                    f.erase(f.find(a[i - x]));
                    s1 -= a[i - x];
                } else {
                    s.erase(s.find(a[i - x]));
                    s2 -= a[i - x];
                }
            }
            
            // Insert the new element into the appropriate multiset
            if ((int)f.size() <= (int)s.size()) {
                f.insert(a[i]);
                s1 += a[i];
            } else {
                s.insert(a[i]);
                s2 += a[i];
            }
            
            int n1 = (int)f.size();
            int n2 = (int)s.size();

            // Rebalance if max of Left > min of Right
            while (n1 > 0 && n2 > 0) {
                int mn = *f.rbegin();
                int mx = *s.begin();  
                if (mn > mx) {
                    // Swap elements and update running sums
                    s1 -= mn; s1 += mx;
                    s2 -= mx; s2 += mn;
                    f.insert(mx);
                    s.insert(mn);
                    f.erase(f.find(mn));
                    s.erase(s.find(mx));
                    n1 = (int)f.size();
                    n2 = (int)s.size();
                } else {
                    break; // Perfectly balanced
                }
            }
            
            // Calculate operations for valid windows
            if (i >= x - 1) {
                int m = *f.rbegin(); // Median
                // Cost = (Elements in left * median - sum_left) + (sum_right - Elements in right * median)
                mvs[i - x + 1] = ((n1 * 1LL * m) - s1) + (s2 - (m * 1LL * n2));
            }
        }
        
        // Initialize DP table with -1
        memset(dp, -1, sizeof(dp));
        
        // Start DP from 0 subarrays picked, at index 0
        return solve(0, 0);
    }
};

/*
*
* Dry Run
*
* Input: nums = [9,-2,-2,-2,1,5], X = 2, K = 2
* 
* Sliding Window (Size X = 2):
* i=0 (val=9): f=[9], s=[], s1=9, s2=0
* i=1 (val=-2): f=[9], s=[-2]. Imbalanced (9 > -2). Swap. 
*               f=[-2], s=[9]. mvs[0] = cost to make [9, -2] equal to -2 => 11
* i=2 (val=-2): outgoing=9. f=[-2], s=[]. incoming=-2. f=[-2], s=[-2].
*               mvs[1] = cost to make [-2, -2] equal to -2 => 0
* i=3 (val=-2): outgoing=-2. f=[-2], s=[]. incoming=-2. f=[-2], s=[-2].
*               mvs[2] = cost to make [-2, -2] equal to -2 => 0
* i=4 (val=1): outgoing=-2. f=[-2], s=[]. incoming=1. f=[-2], s=[1].
*               mvs[3] = cost to make [-2, 1] equal to -2 => 3
* i=5 (val=5): outgoing=-2. f=[1], s=[]. incoming=5. f=[1], s=[5].
*               mvs[4] = cost to make [1, 5] equal to 1 => 4
* 
* Array mvs: [11, 0, 0, 3, 4]
* 
* DP Execution (finding K=2 windows):
* We need to pick 2 non-overlapping values from mvs.
* Best choice: pick mvs[1] = 0 (covers index 1,2) and mvs[3] = 3 (covers index 3,4).
* Total Minimum Operations = 0 + 3 = 3.
*
*/
```

## 🔍 Further Exploration

* **Why Multiset?** C++ `std::set` only stores unique elements. We must use `std::multiset` to correctly handle subarrays containing duplicate values.
* **Cost Calculation Math:** The total operations to make the window equal to median $M$ is mathematically: $\sum_{val < M} (M - val) + \sum_{val > M} (val - M)$. Keeping track of running sums (`s1` and `s2`) lets us compute this in $O(1)$!
